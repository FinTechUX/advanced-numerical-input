Enhanced Number Input

Comma Display

Commas are part of display but not entered values.

Shortcuts

All you need to do is type in k,m,b or t to get a large value number, reducing errors.

Example: 1000, 5k, 2m, 3b, 4t. Works with the basic calculations too!

Basic Calculations

You can perform basic calculations using the following operators: +, -, *, /, ()

Example: 1250 + 250

Live Calculation

Show's the result of the calculation as you type it. Only displays once an operator is present.

Quick Buttons

Quick press buttons to enter regularly used values make it much quicker.

Variables

You can also use the following example variables: IPT (7%), UKVAT (20%)

Example: 1000 + UKVAT will give 1,200.
2m + IPT will give 2,140,000.
100 * UKVAT will give you 20. etc
